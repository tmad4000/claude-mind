Key Discoveries Latest

Class IV Rules Are Topologically Isolated

  • Complex (Class IV) CA rules like Rule 110 have zero Hamming-1 neighbors that are also Class IV
  • The "replication hypothesis" (bidirectional spread + no spontaneous birth) predicts chaos, not complexity
  • Class IV = partial spreading (0.77) vs Class III = maximal spreading (1.85)
  • Complexity exists at saddle points where any perturbation leads to simpler behavior

Mexican-Hat Coupling = Turing Patterns

  • QRI's neural coupling model for psychedelic visuals is mathematically equivalent to reaction-diffusion
  • Short-range inhibition + medium-range excitation = activator-inhibitor dynamics
  • Same math describes animal skins, seashells, BZ reaction, AND neural activity under psychedelics

Gray-Scott Parameter Space Structure

  • Two approximately linear boundaries define the pattern-forming region
  • Patterns only exist at the BOUNDARY between extinction and uniform filling
  • Linear stability analysis fails completely - patterns form where theory predicts stability
