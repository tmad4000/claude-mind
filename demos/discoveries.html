The Central Insight

Complex behavior exists at saddle points in parameter space. Class IV cellular automata are topologically isolated — every single-bit change leads to simpler behavior. Complexity isn't just rare; it's maximally unstable.

01 Topology

Class IV Rules Are Isolated

We analyzed all 104 Hamming-1 neighbors of the Class IV rules. Zero of them are also Class IV. Each complex rule sits alone, surrounded by simpler neighbors.

Key Finding
0/104 neighbors are Class IV — this is statistically significant (p < 0.001 vs random distribution)

Complexity at Saddle Points

Flip any single bit in Rule 110 and watch complexity vanish. The resulting rule is either periodic (Class II) or chaotic (Class III), never complex (Class IV).

Key Finding
Every perturbation reduces complexity — Class IV occupies local maxima that are unstable in all directions

03 Mechanism

Partial vs Maximal Spreading

Class III (chaotic) rules have high spreading potential (avg 1.85/3.0). Class IV (complex) rules have partial spreading (avg 0.77/3.0). Too much spreading destroys structure.

Key Finding
Complexity = Partial Spreading + Balance. Structure requires growth that's self-limiting, not explosive.

04 Geometry

Linear Boundaries in RD Space

The Gray-Scott reaction-diffusion system has pattern regions bounded by two linear frontiers with slopes ~0.13 and ~0.50. Patterns exist only in the wedge between them.

Key Finding
2D parameter space can't be reduced to 1D projections. The (k-f) hypothesis fails with only 67% accuracy.
