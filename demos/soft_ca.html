Soft Cellular Automata

Can we make complexity more robust by "softening" the discrete rules? Explore continuous interpolations between CA rules.

The Experiment

In discrete CA, Class IV rules are isolated saddle points - ANY single-bit change destroys complexity. What if we allow continuous interpolation between rules? Does complexity become more robust, like in reaction-diffusion systems?

What We're Testing

Soft CA: Instead of discrete outputs (0 or 1), each transition outputs a probability, then we threshold. Blend slider interpolates between two rule's probabilities.

Question: Is there a smooth path from complex to simple, or does complexity collapse suddenly even in continuous space?
